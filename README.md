# juntsa.fi

Juntsan sovelluskauppa. Yksi staattinen sivu, ei käännösvaihetta.

Tämä on GitHubin **käyttäjäsivusto**, joten domain `juntsa.fi` (tiedosto
`CNAME`) kattaa myös kaikki muut tämän tilin julkiset repot:
`juntsa.fi/ajokello`, `juntsa.fi/kuvakello` ja niin edelleen. Yhtäkään muuta
repoa ei siis tarvitse siirtää tänne.

Poikkeus: repo jolla on oma `CNAME` pitää oman domaininsa — esimerkiksi
`musarooms` pysyy osoitteessa musarooms.com.

`.nojekyll` estää Jekyll-käsittelyn: tiedostot tarjoillaan sellaisinaan.

## Kesken

- hinnat ja tuotetekstit ovat paikanvaraajia
- kassa puuttuu: myydäänkö lataus vai lisenssi, on päättämättä
- puheharjoittelutyökalun julkinen nimi auki (ei "SpeakHell")
